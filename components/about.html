About Layer One and the author

Layer One is a design systems studio in Bangalore, India. We set up the foundations, scale them across products and markets, and put in the governance that keeps teams using them.

Aniket Pandey

Aniket leads Layer One. His design systems work spans three very different kinds of organisation:

  • JPMorgan Chase, Senior Designer, Design Systems (2025–present): company-wide design patterns, an AI-assisted workflow for drafting them, and tooling that checks design files and code against the system, used by 500+ designers and 1,000+ engineers.
  • CARS24, Design Systems Lead (2024–25): the design system for 70+ designers and 200+ engineers, a new palette and token architecture for the rebrand, governance, and a pattern library, putting 10+ products in three countries on one token system.
  • IBM, UX Designer, design systems (2021–24): design systems for IBM clients including Cardinal Health and Riyadh Air, from foundations and tokens to governance, contribution and releases.

The rules we work by

  1. A design system is an agreement, not a library

  2. Audit before you build

  3. Name things so people can guess them

  4. Tokens first, components second

  5. Accessible by default, not by audit

  6. Every decision comes with a reason

  7. Build where the system lives: your files, your repo

  8. Measure time saved, not usage

  9. Docs decide adoption

  10. Leave the team able to run it without us
